## Run Locally

Follow these steps to run the project on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/dhruti-29/Dhruti-s_Universe.git
```

### 2. Navigate to the project folder

```bash
cd Dhruti-s_Universe
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to explore the portfolio.
